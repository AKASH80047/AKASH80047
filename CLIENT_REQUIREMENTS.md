# 📋 Client Requirements

## Before Starting

To ensure a smooth and fast development process, please provide the following details (where applicable) when requesting freelance work:

* **Project description:** What does the app do?
* **Screenshots / Figma:** Visual references of what needs to be built.
* **Existing GitHub repository:** If I am working on an existing app.
* **Flutter/Dart version:** Which version is your app currently using?
* **API documentation:** Postman collections or Swagger docs if I am integrating an API.
* **Firebase configuration:** Requirements for database structure or auth rules.
* **Expected behavior:** How should the final feature work?
* **Deadline:** When do you need this delivered?
* **Acceptance criteria:** A checklist of what makes the task "complete".
* **Relevant reference application:** Links to competitor or similar apps.

This reduces unnecessary back-and-forth and allows me to start coding faster!
