# 🛡️ Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability within my public repositories, please do NOT create a public issue. 

Please send an email to **[akp991892@gmail.com](mailto:akp991892@gmail.com)** with the details.

## 🔒 Client Privacy & Secrets

When submitting a task request or issue:
* NEVER publicly post API keys.
* NEVER share passwords or access tokens.
* NEVER upload private credentials (like `google-services.json`).
* NEVER expose private customer data.

If a project requires me to use your API keys or private credentials, we will securely share them privately via encrypted channels once the project begins.
